# SBCSAE 对话事件五分类标注体系

## 1. 标注任务

每条数据是一小段两人对话，其中标出了一个“目标位置”。

标注者需要听目标位置前后的声音，判断该位置发生了哪一种对话行为，并从下面五个标签中选择一个：

`C / BC / T / I / NA`

判断时以音频为准。文字转写只用于帮助理解内容和区分说话人。

## 2. 每条数据包含什么

- 一段对话音频：包含目标位置之前和之后的上下文。
- 一个目标位置：需要判断的具体时刻或短时间范围。
- 两位说话人：用 `A` 和 `B` 表示，只代表两位不同的人。
- 对话文字：可能存在漏字、错字或时间误差，不能代替听音频。

标注的对象不是整段音频，而是音频中标出的目标位置。

## 3. 五个标签

| 标签 | 名称 | 什么时候选择 | 简单例子 |
|---|---|---|---|
| `C` | 继续 | 目标位置之后仍是原说话人继续掌握对话 | A说话 → 停一下 → A继续 |
| `BC` | 简短反馈 | 另一人只作简短回应，表示在听或理解，没有接管对话，可以理解为“嗯”“啊”| A说话时，B说“嗯、对、是吗”，随后A继续 |
| `T` | 换人 | 前一人已经结束或让出说话机会，另一人自然接着说 | A说完 → B开始并继续说 |
| `I` | 插话或打断 | 前一人还没有结束，另一人已经进入，并开始表达内容或争取说话权 | A还在说，B就开始表达自己的话 |
| `NA` | 无人说话 | 目标位置双方都没有说话 | 目标位置是一段双方静音 |


## 4. 容易混淆的情况

### BC 和 I

- 只是“嗯、对、是吗”等听者反馈，没有想接管对话：`BC`。
- 开始表达新的内容、提出问题、反对或试图取得说话权：`I`。
- 不能只看声音长短，要判断这句话在对话中的作用。

例如，“对”可能是 `BC`，但“对，可是我觉得……”是在表达内容，可能是 `I`。

### T 和 I

- 前一人已经说完，后一人才开始：`T`。
- 前一人还在说，后一人已经开始表达内容：`I`。
- 两个人只有很轻微的交接重叠，但听起来是自然换人：`T`。

### C 和 T

- 停顿前后还是同一个人继续主要内容：`C`。
- 停顿后换成另一人开始主要内容：`T`。

### BC 和 T

- 简短回应后，原说话人继续：`BC`。
- 回应者在目标位置之后继续展开内容并掌握对话：`T`。

### I 和普通重叠

- 只有笑声、咳嗽、呼吸声或无意义杂音，不标 `I`。
- 两人一起说出相同词语，或者自然完成对方的话，不一定是 `I`。
- 另一人进入后开始表达自己的内容或争取说话权，才标 `I`。

## 5. 必须遵守的原则

- 必须听目标位置之前和之后，不能只听目标点的一瞬间。
- 以听到的声音和对话作用为准，不能只根据文字中的“嗯、对”等词判断。
- 不根据说话人的身份、语气好坏或观点是否正确判断标签。
- 不因为停顿很短就一定标 `C`，也不因为有重叠就一定标 `I`。
- 每条数据只能选择一个五分类标签。
- 如果目标位置错误、音频损坏或确实无法听清，应另外记录问题原因，不要随意猜测。

## 7. 标注结果

每条数据需要记录：

- 一个标签：`C / BC / T / I / NA`；
- 可选备注：只在存在歧义或数据问题时填写，例如“只有笑声”“目标位置偏早”“两人同时开始”。

机器自动生成的候选标签不是标准答案。人工标注者应独立听音频后再作判断。
